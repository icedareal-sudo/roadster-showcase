Can I book a test drive or flight session?

Yes. Use the booking form and choose the session type that matches your interest, whether it is a test flight or premium preview.

Why is there no backend account system?

Because this is a front-end prototype. The account and booking flows are implemented on the client side so the UI works correctly without a real database.

Why do the buttons need to work?

Buttons need real anchor behavior or JS event handlers. Here, they scroll to the relevant section and submit mock booking/account data locally.

Is this a real production backend?

No. This page is a polished front-end concept. It is ready for a real backend integration later, but it functions correctly as a single-page experience.

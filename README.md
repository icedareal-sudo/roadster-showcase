# Roadster cinematic landing page

This repo contains a polished, premium Roadster-inspired landing page designed to feel cinematic, minimal, and futuristic.

## Run locally

Open `index.html` directly in a browser, or use a simple local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deploy to Vercel

1. Push this repo to GitHub.
2. Import the repo in Vercel.
3. Keep the default settings.
4. Deploy.

## Notes

- The page is built as a static site for fast deployment.
- It uses premium background imagery from Tesla's public assets.
- It is ready for iteration if you want a more custom brand or a stronger Elon-documentary cinematic look.
